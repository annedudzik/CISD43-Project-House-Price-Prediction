# CISD43-Project-House-Price-Prediction
This project analyzes a House dataset provided in class and generates two machine learning models, linear regression and KNN, to predict house price based on the numbers of bedrooms and bathrooms, and square feet of living space. The model has only 3 predictor values, all of which are easy to find in real estate listings.
The project includes a Jupyter notebook for Python code, a notebook for MongoDB queries, PDFs, and documents containing RapidMiner and MonogoDB image walkthroughs.
